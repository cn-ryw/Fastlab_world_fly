# DA360 v1 experimental calibration

This directory intentionally contains only the runtime parameters and a
sanitized aggregate report. Raw RGB images, depth arrays, poses, anchor lists,
flight paths and location identifiers are not published.

The calibration failed the automatic accuracy gates. It is retained only as a
manually accepted sim-to-sim baseline and must not be interpreted as a real
world accuracy or safety certification. The input projection and checkpoint
identity must match the values in `depth_calibration.json`.
