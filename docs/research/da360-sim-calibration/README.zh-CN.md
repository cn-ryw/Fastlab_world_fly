# DA360/Cesium 仿真尺度标定补充材料

这组图记录的是 **Cesium 仿真几何真值与 DA360 预测之间的 sim-to-sim 对比**，不是现实相机或真实飞行传感器数据。目录名称和说明特意使用 `sim-calibration`，避免把仿真实验误解为真实世界标定。

## 标定关系

DA360 输出已经消除平移不确定性的 scale-invariant disparity。这里仅拟合尺度：

```text
1 / D = a * p
```

其中 `D` 是米制深度，`p` 是 DA360 输出的相对视差，`a` 是尺度系数；外部偏移固定为 `b=0`。本目录中的计算没有使用仿射偏移项。

## 数据范围与主要结果

- 4 个仿真地点，共 12 次采集。
- 每次采集使用 `8×16` 的 Cesium 射线锚点网格，共 1,536 个候选格点。
- 获得 1,140 个命中点、204 个未命中点，另有 192 个极区排除点。
- `0.5–20 m` 范围内共有 833 个可比较锚点。
- 候选格点有效覆盖率为 `74.22%`，射线尝试命中率为 `84.82%`。
- 汇总尺度系数为 `a=0.00118928121859`。
- 留一地点验证的中位 AbsRel 为 `37.57%`，p90 AbsRel 为 `150.70%`，自动精度门禁未通过。

这些结果说明：当前尺度可作为人工检查后的仿真基线，但单一固定尺度尚不能被表述为跨地点、跨场景或真实传感器的可靠米制标定。

## 图表说明

- `figure1_cesium_anchor_sampling.*`：展示锚点采样覆盖、未命中位置和极区排除情况。
- `figure2_da360_vs_cesium_sparse_truth.*`：只在实际记录的稀疏 Cesium 射线位置比较 DA360 深度，不把稀疏真值伪造成稠密深度图。
- `figure3_capture_scale_absrel.*`：展示逐次采集尺度漂移，以及留一地点验证中的中位和 p90 相对误差。

每张图提供 PNG、可编辑 SVG 和 PDF。图中的英文轴标签保留用于论文和技术交流；项目 README 使用另行整理的简体中文总览图。600 dpi TIFF 可由脚本重新生成，因此不纳入 Git 版本历史。

## 源数据与复现边界

- `source_data/figure1_anchor_status.csv`
- `source_data/figure2_sparse_depth_comparison.csv`
- `source_data/figure3_capture_metrics.csv`
- `plot_sim_calibration_figures.py`

CSV 保留了图表所需的仿真锚点和汇总指标，不含本机绝对路径、浏览器标识、遥控器设备标识或访问凭据。绘图脚本还会校验本地证据归档与原始拟合报告；这些体积较大的原始归档不随公开仓库分发，因此公开仓库可审计图中数据，但不能单独重放完整的原始采集过程。

## 结论边界

- Cesium 真值是稀疏射线距离，不是稠密 ground-truth 深度图。
- 锚点是嵌套在 12 次采集中的空间样本，不应当作 833 次独立实验。
- 没有重复推理种子，因此不报告置信区间、显著性检验或 p 值。
- 自动精度门禁失败与“允许继续进行 sim-to-sim 飞行测试”并不矛盾，后者只是人工工程决策，不代表标定精度验收通过。
